# 🎙️ Voice Changer

Изменение голоса в реальном времени, саундборд и озвучка текста в одном приложении для Linux.
Работает как виртуальный микрофон, поэтому голос можно подать в Discord, OBS, Telegram, игры и любые другие программы.

## Возможности

**🎚️ Смена голоса**
- Десятки готовых пресетов: «Глубокий голос», «Бурундук», «Демон», «Монстр», «Робот», «Рация / радио», «Мегафон», «Пришелец», «Космонавт», «Призрак» и другие.
- «Случайный голос» и сохранение собственных пресетов (ПКМ по своему пресету — удалить).
- Кнопки «Заглушить» и «Оригинал» (быстрый обход эффектов) с плавным переключением.
- Индикаторы уровня на входе и выходе, запись обработанного голоса в WAV.

**🔊 Саундборд**
- Загрузка собственных звуков: WAV, MP3, OGG, FLAC, M4A, AAC, OPUS.
- Плеер с волной звука: перемотка кликом, пауза, переход к предыдущему и следующему звуку.
- Горячие клавиши: `Ctrl+1…9` — звуки, `Ctrl+←` / `Ctrl+→` — переключение пресетов.

**🗣️ Озвучка текста**
- Нейросетевой голос [Piper](https://github.com/OHF-Voice/piper1-gpl): работает офлайн, есть русские голоса (Ирина, Денис, Дмитрий, Руслан) и английские, украинский, немецкий, испанский.
- Голоса скачиваются прямо из приложения. Если HuggingFace недоступен, есть зеркало, поддержка HTTP-прокси и ручное добавление файлов.
- Регулировка скорости речи. Запасной движок: espeak-ng.

**🎤 Виртуальный микрофон**
- Создаёт виртуальное устройство `VoiceChanger_Mic` через PipeWire / PulseAudio.
- Опция «Слышать себя в наушниках».

**🎨 Оформление**
- Тёмная и светлая темы, плавные анимации.
- 7 градиентных тем, 6 однотонных акцентов и **свой цвет или градиент** на любой вкус.

## Установка

### Вариант 1. Готовый AppImage (проще всего)

1. Скачай `VoiceChanger-x86_64.AppImage` со страницы [Releases](https://github.com/Yewound/voicechanger/releases).
2. Сделай файл исполняемым и запусти:

```bash
chmod +x VoiceChanger-x86_64.AppImage
./VoiceChanger-x86_64.AppImage
```

Если система ругается на FUSE, запусти так:

```bash
./VoiceChanger-x86_64.AppImage --appimage-extract-and-run
```

### Вариант 2. Из исходников

```bash
git clone https://github.com/Yewound/voicechanger.git
cd voicechanger
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

## Системные зависимости

| Что | Зачем | Обязательно |
|---|---|---|
| PipeWire (с `pipewire-pulse`) или PulseAudio, утилита `pactl` | виртуальный микрофон | нет, без него не будет виртуального микрофона |
| `ffmpeg` | звуки в форматах MP3, OGG, M4A и др. | нет, WAV работает и без него |
| `espeak-ng` | запасной движок озвучки (звучит как робот) | нет |
| `piper-tts` | живой голос озвучки | нет |

Установка на Arch / CachyOS:

```bash
sudo pacman -S espeak-ng ffmpeg
pipx install piper-tts
pipx ensurepath        # затем открой терминал заново
```

> ⚠️ Не ставь пакет `piper` из репозиториев Arch — это совсем другая программа (настройка игровых мышей). Нужен именно **`piper-tts`**.

## Как использовать

1. Выбери микрофон и устройство вывода на вкладке с устройствами.
2. Включи «Виртуальный микрофон», если хочешь использовать голос в Discord, OBS и т. п.
3. Выбери пресет и нажми **«Включить»**.
4. В нужной программе выбери микрофоном **`VoiceChanger_Mic`**.

### Озвучка текста

1. Напиши текст, выбери язык и голос.
2. Нет живых голосов? Нажми **«Скачать голос…»**: Ирина (женский) и Денис, Дмитрий, Руслан (мужские) для русского.
3. Нажми **«Сказать»**: фраза прозвучит в микрофон. Движок должен быть включён.

Голоса сохраняются в `~/.config/VoiceChanger/voices`. Если скачивание блокируется, скачай файлы `.onnx` и `.onnx.json` одного голоса вручную (через VPN или с другого устройства) со [страницы голосов Piper](https://huggingface.co/rhasspy/piper-voices/tree/main) и добавь их через **«Скачать голос… → Добавить голос из файла…»**.

## Частые проблемы

**Щелчок при нажатии «Включить».** Обычно это не сам звук, а звуковая карта «просыпается» после простоя. Включи в настройках устройств переключатель **«Не усыплять звуковую карту»**. Либо отключи засыпание в WirePlumber:

```bash
mkdir -p ~/.config/wireplumber/wireplumber.conf.d
cat > ~/.config/wireplumber/wireplumber.conf.d/51-no-suspend.conf <<'EOF'
monitor.alsa.rules = [
  {
    matches = [ { node.name = "~alsa_output.*" } ]
    actions = { update-props = { session.suspend-timeout-seconds = 0 } }
  }
]
EOF
systemctl --user restart wireplumber
```

**«Piper не найден».** Убедись, что он установлен (`pipx install piper-tts`) и выполнен `pipx ensurepath`. Приложение ищет Piper в `PATH`, в `~/.local/bin` и в окружении pipx.

**Голос не слышен в Discord / OBS.** Проверь, что включён «Виртуальный микрофон», движок запущен, а в Discord или OBS в качестве микрофона выбран `VoiceChanger_Mic`.

## Сборка AppImage

Скрипт сборки лежит в репозитории:

```bash
./build.sh
```

Нужны `pyinstaller` и `appimagetool` (скрипт подскажет, чего не хватает). Результат — файл `VoiceChanger-x86_64.AppImage`.
